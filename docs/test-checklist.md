# 进游戏验收清单（模型模式 / 比例·齿轮 / 可控施力点 / 新配置界面）

> 用法：按 Y 进入模型模式后逐条对照。截图丢进 `run/screenshots`，我按最新一张看。
> 每条后面是「出问题最可能的原因」，方便你描述现象时直接对上。
>
> **本轮（GUI 架构重构 + 投影修正）新增的重点在 §8–§12**，其余条目是回归。

## 0. 进入与退出

| 步骤 | 期望 |
| --- | --- |
| 普通模式按 **Y** | 进入模型模式：提示、光标释放、左上/左/右三栏出现、玩家被钉住不能走动 |
| 多选模式（Ctrl）或整组拖拽中按 Y | **拒绝**并提示「只能从普通模式进入模型视图」 |
| 再按 Y / Esc | 退出，鼠标交回游戏，视角与站位与进入前一致 |
| 进入后按 **Tab** | 自由光标 ↔ 锁定准星 切换 |
| 进入模型模式后按 **Ctrl+O** 开设置界面再关掉 | 光标应仍是自由的（不该被抢回去） |

## 1. 相机（SolidWorks 那套）

| 操作 | 期望 |
| --- | --- |
| 中键拖动 | 绕模型旋转；几何不动 |
| Ctrl + 中键拖动 | 平移视野 |
| Shift + 中键上下拖 / 滚轮 | 缩放；滚轮以**光标附近**为中心 |
| 空格 | 弹出视图定向菜单（前/后/左/右/上/下/等轴测） |
| 退出再进入 | 相机重新按玩家视角摆位，不留上一次的怪角度 |

## 2. 选择与描边（几何基准是**方块碰撞箱**）

| 情况 | 期望 |
| --- | --- |
| 所有可见模型 | 细线描边（不遮挡方块本身太多） |
| 鼠标划过 | 高亮鼠标下的那个**点/棱/面**（面=四条边、棱=一条、点=小方块） |
| 半砖 / 楼梯 / 栅栏 / 火把 | 高亮应贴合**碰撞箱的那个子盒**，而不是整格；火把这类无碰撞箱的应回退到轮廓箱 |
| 左键点模型 | 该模型描边变成暖色加粗（选中） |

## 3. 左键拖动模型（解锁 → 缓移 → 锁定）

| 步骤 | 期望 |
| --- | --- |
| 没跑任何功能时，左键按住并拖动模型 | 模型**缓慢**跟着走（不是瞬移），松手即停，不甩飞 |
| 拖动时看其它结构 | 若它与被拖的结构有配合，应被带着走 |
| 快速甩动鼠标 | 不超过限速（9 格/秒），不会攒出巨大动量 |

## 4. 配合 / 比例 / 齿轮

| 功能 | 步骤 | 期望 |
| --- | --- | --- |
| 配合 | 上边栏「配合」→ 选 2 个元素 → 左栏出现可选类型 → 选类型 → 完成 | 建立成功；树状图该模型下的「配合」出现新条目；结构缓慢吸附到位 |
| 配合参数 | 树里点该配合 → 左栏改数值 / 勾反转 | 解锁→缓移→重新锁定，不出现「越转越快」 |
| 限制 | 类型选「限制」，设 min/max（如 0.5 / 3.0） | 区间内自由滑动，超出被挡住 |
| 比例 | 上边栏「比例」→ 选 **3 个以上**面（最后选的是基准）→ 完成 | 建组成功；移动基准面，其余结构按各自 k 跟随 |
| 比例参数 | 树里点该比例组 → 左栏改某一行的 k | 下一子步就按新比例跟随 |
| 齿轮 | 上边栏「齿轮」→ 按顺序选 4 条线段（固定轴A、齿轮轴A、固定轴B、齿轮轴B）→ 完成 | 建组成功；转动 A 时 B 按 −ratio 反向转；默认 20:40 |
| 齿轮参数 | 左栏改齿数 / 勾反转 | 传动比随之改变，传动方向反向 |

**注意**：齿轮的「固定轴」是机身/世界的参考轴（不是另一根啮合轴）；四条线要选得让齿轮轴与固定轴**不平行**，否则面板会提示退化且不产生运动（这是刻意的，避免抖动值）。

## 5. 可控施力点

| 步骤 | 期望 |
| --- | --- |
| 上边栏「模型」→「施力点」，或树里「＋ 添加施力点」 | 进入放置模式 |
| 鼠标在模型表面移动 | 有**落点预览**（黄） |
| 左键点击表面 | 放置成功；自动在左栏选中它；树里「可控施力点」出现新条目 |
| 左栏 | 力大小滑条（0–1000N，步进 1）+ 输入框；频道补全框（输入 `redstone` 应出现 `minecraft:redstone_torch` 等）；自定义名输入框；开启复选框；删除按钮 |
| 频道填 `minecraft:redstone_torch` 后开启 | 用 Create 红石链接（两槽都放红石火把）发信号 → 结构沿**该点表面法线**受力；无信号时不动 |
| 标记颜色 | 绿=启用且频道配好；琥珀=启用了但频道没配好；灰=未启用 |
| 换结构朝向 | 力方向跟着结构一起转（力贴在表面上） |

## 6. 配置界面（Ctrl+O 或模组列表 Config）

| 步骤 | 期望 |
| --- | --- |
| 打开 | 背景模糊；左侧蓝块自上而下 → 标题左→右 → 三个大类图标依次滑入 |
| 点一个大类 | 大图标移动+放大；右侧折线蓝块展开；设置项从右往左滑入并沿折线滚动 |
| ESC | 反向退回大类界面 |
| 设置 → 关闭「界面动画」 | 上面所有动画直接到位（不再有缓动） |
| 设置 → 界面字号缩放 | 界面文字随之变大变小 |

## 7. 已知的、还没做的

- 施力点的力大小单位是「牛顿」，与游戏内其他力的量级是否协调需要实测手感（数值可调）。
- 「隐藏」模型目前只影响描边与选择，**不会**让方块本身不渲染（真正的整块隐藏要挂进 Sable 的渲染管线，下一步做）。
- 属性开关（碰撞/锁定）的初始值是客户端本地镜像，还没读服务端的同步包（改过之后以你操作的为准）。
- 控制 HUD 正在迁移到新库（本清单不涉及）。
- 碰撞箱描边的开销**没有实测过**：大结构（上千方块）上若掉帧，第一处要优化的就是
  `SubLevelOutlineRenderer.collisionBoxes`（已加一帧内缓存，但没量过）。

## 8. 【本轮】滑条 ↔ 输入框联动

> 上一轮反馈「设置施力点时滑动条和输入框没有联动」。根因是两边各存了一份值。
> 现在两者绑的是同一个状态，请重点看：

| 步骤 | 期望 |
| --- | --- |
| 拖动「力的大小」滑条 | 右边输入框的数字**逐帧**跟着变 |
| 在输入框里打字 | 滑条**立刻**跟着滑（不用回车） |
| 输入框里回车 | 数值保持不变，服务端收到一次命令 |
| 输入框里输入超范围（如 99999） | 松手/回车后被夹到上限，两边一致 |
| 输入非法字符 | 被拒绝输入；退出编辑后回到当前值（等于自动撤销） |
| 点击输入框 | 内容**全选**（可以直接打新数字覆盖，不需要先删） |
| 拖动滑条松手 | 只在松手时发一次包（不是拖动过程中一路发） |
| **滑条能拖动** | 上一版整行高度是 0（`prefH` 留了 `AUTO` 而容器没实现 `measure`），按下落在 `UiField` 自己身上 → 拖不动。现在应当正常拖动 |

## 12. 【本轮】标记与投影的精度

| 步骤 | 期望 |
| --- | --- |
| 鼠标停在某个面的角上 | 黄色小方块**正压在那个角**上，不该有可见偏移 |
| **中键拖动旋转的同时**看标记 | 标记应该**牢牢粘在几何上**（上一版的偏移就是「画面用的相机比投影用的相机慢一帧」，转动时最明显） |
| 松开中键再看 | 仍然贴合 |
| 日志 | `[model-diag] frame=... stale=...px cursorDist=...px`：`stale` 应接近 **0**（大于几像素就说明相机推进时机又跑到渲染之后去了）；`cursorDist` 应小于标记的抓取半径 |

## 13. 【本轮】模型描边按碰撞箱

| 步骤 | 期望 |
| --- | --- |
| 半砖 / 楼梯 / 栅栏 | 描边贴合它自己的碰撞箱（半砖只有半格高），不再是一整格方框 |
| **平坦的墙面 / 甲板** | **只有外轮廓**，表面内部没有网格线（上一版把内部接缝判定写死了，整块平面被切碎成网格） |
| 大结构（几百到上千方块） | 帧率不应明显下降；若下降请告诉我规模 |
| 日志 | `[model-diag] outline[contour] blocks=... edges=... culled=...`：`culled` 应当和 `edges` 同量级（`culled=0` 就是接缝剔除又失效了） |
