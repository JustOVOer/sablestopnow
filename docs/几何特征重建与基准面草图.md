# 从模型重建几何特征 + 以模型面为基准面的草图（研究 / 设计）

> 状态：**研究稿**（未动工）。目标是把"模型上的面 / 棱"变成**一等公民**，并让新建草图可以直接
> **点在模型的一个平面上**开始画，同时把该平面上的**直线边**作为草图里**常驻、不可移动、但仍可被约束**的参考线。

---

## 1. 目标（拆成三个可独立验收的能力）

| # | 能力 | 验收标准 |
|---|---|---|
| F1 | **特征图（FeatureGraph）**：从实体重建 面 / 棱 / 顶点，带参数化来源 | 立方体 ⇒ 6 面 12 棱；L 形 ⇒ 6 面；圆柱 ⇒ 2 盖面 + 1 柱面；切割后 ⇒ 洞壁作为独立面 |
| F2 | **点面建草图**：鼠标点模型的一个平面 ⇒ 以它为草图基准面 | 面高亮（整面）→ 点击 → 进入草图，草图的 u/v 与**该面的边**对齐 |
| F3 | **参考线**：该平面上的直线边 ⇒ 草图内常驻参考线 | 不可拖动/不可删/不计自由度；可以被 COINCIDENT / PARALLEL / 距离 / 角度约束 |

## 2. 我们已有的素材（决定"解析式优先"）

| 现有资产 | 位置 | 对本任务的用处 |
|---|---|---|
| `SolidMesh.Vertex(position, normal, u, v)` + `Mesh` | `sketch/SolidMesh.java` | 网格已在**局部坐标**里；`faceKind` 还能区分"盖子 / 侧面" |
| `Solid.Shape` = `Extrusion / Revolution / Cut` | `sketch/Solid.java` | **参数化真相**：面可以**精确枚举**，不需要从三角形反推 |
| `Extrude.boxesOf(...)` | `sketch/Extrude.java` | 棱柱的盒子分解，碰撞与"平面/侧面"判定都靠它 |
| CSG（`Csg` + `CsgMesh`） | `sketch/csg/` | 切割后是**三角汤** ⇒ 这部分只能走网格路线 |
| `SketchPlane(origin, axisU, axisV)` | `sketch/SketchPlane.java` | 面 ⇒ 基准面的落点；已可序列化 |
| `Sketch.construction`（String key） | `sketch/Sketch.java` | 参考线可以复用这套"标记 + 持久化"机制 |
| `SketchDof` 自由度分析 | `sketch/SketchDof.java` | 参考线要**排除**在这里之外 |
| `SketchProfiles` 轮廓提取 | `sketch/SketchProfiles.java` | 参考线必须**不进轮廓**（否则会把轮廓切开） |

**结论**：主线走「解析式」（从 `Shape` 枚举面，精确、便宜、和参数化不脱节）；
CSG 结果与未知形状走「网格式」兜底；两者产出的都是同一个 `FeatureGraph`，上层（拾取 / UI / 草图）不区分来源。

## 3. 数据模型

```
FeatureGraph
├─ faces   : Face[]        // 平面 / 圆柱 / 其它
├─ edges   : Edge[]        // 直线 / 圆弧
└─ vertices: Vertex[]      // 只保留"棱的端点与交点"

Face
  kind        : PLANAR | CYLINDER | OTHER
  plane       : (origin, normal)            // PLANAR 才有
  axis        : (origin, direction, radius) // CYLINDER 才有
  loops       : Edge[][]                    // 外环 + 内环（洞）
  area        : double
  provenance  : PARAMETRIC(shape, faceIndex) | MESH(triangles)

Edge
  kind        : LINE | ARC
  a, b        : Vec3     // LINE
  center,r,a0,a1,ccw : ...  // ARC
  faces       : [Face, Face]  // 相邻面（边界边只有 1 个）
```

**关键点**：`provenance` 保留"这个面是从哪个参数化面来的"，将来 player 改参数（改拉伸深度）时
可以直接**重映射**，不必整图重建。

## 4. 两条提取路线

### 4.1 解析式（首选，覆盖未切割实体）

- **拉伸（Extrusion）**：
  - 盖面 2 个：轮廓多边形（含内环）= `SketchProfiles` 的轮廓，平面 = 草图平面 / 偏移面
  - 侧壁：轮廓**每一段**一个面 —— 直线段 ⇒ 平面四边形（法线 = 段方向 × 拉伸方向）；
    圆弧段 ⇒ **圆柱面**；贝塞尔 ⇒ 按 32 段弦盒近似成一组平面条带（或标记为 OTHER）
- **旋转（Revolution）**：母线每段 ⇒ 一个旋转面（圆锥 / 圆柱 / 圆环）；两端盖面
- **优点**：面精确、边就是轮廓段（可直接当参考线）、O(轮廓段数)
- **代价**：切割之后参数化就不完整了 ⇒ 见 4.2

### 4.2 网格式（CSG 结果与未知形状）

标准流水线（业界成熟做法 ✓）：

1. **焊接（welding）**：位置量化（1e-4）合并顶点 ⇒ 建邻接
2. **半边或 edge-map**：`(min,max)` 顶点对 ⇒ 边 → 相邻三角形（我们 `CsgMesh.sharpEdges` 里已有雏形）
3. **共面区域生长**：从最大三角形起，按 `|n·n'| > cos(1°)` 且 `点到平面距离 < 1e-3` 扩散；
   平面拟合用**面积加权最小二乘**（或 PCA），不要只取首个三角形
4. **边界环**：只被 1 个三角形使用的边 ⇒ 串成环（贪心按转角连通）；支持多环（外环 + 洞环）
5. **段拟合**：环上折线用 **Douglas–Peucker**（容差 1e-3）合并共线 ⇒ 直线段；
   残差仍大的连续段用**三点定圆 + 残差检验**判为圆弧
6. **丢弃噪声**：面积 < 1e-6 的三角形直接跳过（CSG 会产生细碎三角形）

> 参考：平面检测的两大主流是**区域生长**与 **RANSAC**（点云文献里对比很多，例如
> [HAL 的平面分割综述](https://hal.science/hal-04546355v1/file/VF.pdf#2#3#2)、
> [ENPC 博士论文对 RANSAC/区域生长的比较](https://pastel.hal.science/tel-03764907v1/preview/TH2022ENPC0023.pdf#page=2#5#14#5)）；
> 半边结构可参考 Java 实现 [jTEM HalfEdge](https://www3.math.tu-berlin.de/geometrie/jtem/halfedge/api/de/jtem/halfedge/util/HalfEdgeUtils.html)
> 与 [micycle1/PMesh](https://github.com/micycle1/PMesh#1)（**都只作参考，我们自己写**，避免许可问题）。

## 5. 点面建草图（F2）

### 5.1 拾取
- 射线 vs 三角形（Möller–Trumbore），取**最近**命中；命中三角形 ⇒ 查 `FeatureGraph` 得到整面
- **优先级**：`面 > 基准板`（与之前定过的"先试面、再试板"一致）
- 命中后：**整面高亮**（半透明填充 + 描边），并在面质心附近显示"以该面建草图"提示

### 5.2 面 ⇒ 基准面
- `origin`：面的**质心**（对平面而言在面内 ✓）
- `axisU`：面内**最长直线边**的方向（让参考线是水平/竖直的，玩家最省事）
- `axisV` = `normal × axisU`（右手系，`SketchPlane` 已是这套约定）
- 若面是**圆柱** ⇒ 不给基准面（提示"该面不是平面"）；可选：给"轴线"作为参考

### 5.3 与现有 `SketchClient` 阶段机的接法
现在阶段是 `SELECT_BODY → SELECT_PLANE → EDITING`；`SELECT_PLANE` 里的候选是**三块基准板**。
新增：候选里加入"模型的面"（排在最前），命中即用该面平面；其余流程不变 ✓

## 6. 参考线（F3）—— 最需要小心的部分

### 6.1 表示
- `Sketch.Entity` 新增标记 **`reference`**（NBT 键 `"reference"`，缺失 ⇒ false，旧存档安全 ✓）
- 与 `construction` 的区别：`construction` 是"玩家画的辅助线"（可拖、可删）；
  `reference` 是"从模型带过来的参考几何"（**不可拖、不可删、不可改**）

### 6.2 不可移动怎么实现（两种，选一种）
| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| A. 加 `FIXED` | 两条端点各 2 条 `FIXED`（共 4 条） | 复用现有求解器，零改动 | 4 条约束会**吃掉自由度** ⇒ 需要 DOF 分析里把 reference 实体排除 |
| B. 求解器忽略 | `SketchSolver` 侧把 reference 顶点当"常量" | 语义最干净 | 要动 ABI 层，风险高 ✗ |

**选 A**：`SketchDof` 里**跳过 reference 实体**（既不算它的自由度，也不算它的约束）⇒ 玩家看到的自由度与 SolidWorks 一致 ✓

### 6.3 仍可被约束
- `pickEntity` 正常返回 reference 实体 ⇒ 玩家可以给它加 `COINCIDENT` / `PARALLEL` / `PERPENDICULAR` / 距离 / 角度 ✓
- 只**禁止**：拖动端点、删除、改成辅助线
- 参考线**不进轮廓**（与 `construction` 同处理）✓ 否则会把拉伸轮廓切碎 ✗

### 6.4 生成规则（"把该平面的直线作为参考线"）
- 遍历该面的**边界环**，只取 `Edge.kind == LINE` 的段
- 投影到草图平面（面本身是平面 ⇒ 恒等投影 ✓），原样长度
- 圆弧段：**不生成**（避免无用负担）；如果玩家需要，可以用"投影曲线"（后续功能）
- 生成时机：`SketchSession` 进入 EDITING 且该草图是本会话**新建**的 ⇒ 自动加；
  已有草图**不重加**（否则会越加越多 ✗）

### 6.5 渲染与 UI
- 颜色：参考几何灰色偏紫（`REFERENCE_COLOR`），与 `construction`（灰蓝）区分
- 左侧面板：新增"参考几何"分组，行尾标注"参考"，不提供删除按钮
- 画布上：参考线**不能选中拖动**（拖动被拦截并提示"参考几何不可移动"）

## 7. 性能与缓存

- 特征图按 `(solid.id, solid.index, shapeHash)` 缓存；`Solid` 被编辑 / 删除 ⇒ 失效
- 网格式提取：几千三角形 ⇒ 单次 < 10 ms；**绝不能在渲染帧里重建** ⇒ 回到"缓存 + 事件失效"
- 面高亮每帧只画命中的那一个面（三角形集合已缓存）

## 8. 离线用例（可断言，不依赖游戏）

| 用例 | 断言 |
|---|---|
| 立方体（`SolidMesh.fromBoxes`） | 6 面、12 棱、每面 4 条直线边 |
| L 形拉伸 | 面数 = 8（2 盖 + 6 侧）、棱数 = 18 |
| 圆柱（弦盒近似） | ≥ 3 面、含 2 个平面盖面 |
| 切割后的立方体 | 面数 > 6，洞壁 4 个平面、每个含 4 条直线边 |
| 参考线 | 在立方体某面建草图 ⇒ 4 条 reference；`SketchDof` 不计它们；对一条线加 `COINCIDENT` 有解 |
| 序列化 | 存/读一轮后 `reference` 标记保留，且不参与轮廓 |

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| CSG 噪音三角形导致面破碎 | 先焊 + 面积阈值 + 共面生长的"容忍微小偏差" |
| 参考线让草图**过定义** | 与 SolidWorks 一致：允许并提示（我们已有 over-defined 机制） |
| 面太多（曲面细分）导致拾取慢 | 面高亮只画命中面；用 BVH 或按体的包围盒粗筛 |
| 参数化与切割混合后 provenance 失效 | 有 `Cut` 的实体整体走网格式；不混用 |
| 参考线多了以后玩家看不清 | 参考几何默认**淡显**，可一键隐藏（沿用现有"辅助线显示"开关） |
