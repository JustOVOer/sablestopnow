# 特征系统 v3 —— 设计文档（草图/特征/渲染/UI 的下一步）

> 状态：**已确认方案**（用户 2026-10-24 回复"全默认"）。本文是实现依据；未列出的细节按"与现有约定一致"处理。
> 范围：用户提出的 0–12 共 13 项。**里程碑拆分 M0–M6**，每个里程碑单独开目标、单独提交。
> 硬性纪律：**每个目标完成时不开客户端**（用户没时间测）；完成后**自查代码 + 自查 GUI 层叠**；只跑 `tools/verify.sh`。

---

## 0. 总原则

1. **不破坏现有行为**：新功能默认"加，不改"；必须改的地方在提交信息里写明"为什么不得不改"。
2. **特征树 = 操作顺序**（item 4）：树序即求值顺序；任何顺序调整都要过依赖检查。
3. **依赖显式化**：每个特征记录它引用的输入（草图 / 基准面 / 棱 / 面 / 其它特征），求值前做一次拓扑排序，循环或悬空 ⇒ 拒绝操作并提示。
4. **预览与提交分离**（item 5）：进入某个模型操作就显示**黄色线框预览**；输入框回车 = **只更新预览**；"确认"按钮 = 真正写数据。
5. **颜色全部可调**（item 2）：所有硬编码颜色改为"调色表 + 默认值"，GUI 里可改，存配置。
6. **渲染单一来源**：所有线条（草图、尺寸、预览、特征高亮）都走同一个 3D 棒图元，禁止再出现 2D 线/HUD 线混合。
7. **GUI 纪律**（踩过的坑）：调试用的置顶/高亮必须当场移除或默认关闭并打印状态；每个 GUI 里程碑对照 `docs/GUI规范-自查清单.md`。

## 1. item 0：3D 线条（有长、宽、厚）+ 尺寸线条全部 3D

### 现状问题
- 线条是"平面内的四边形细条"：**没有厚度**，且宽度方向由 `quadUp` 决定 —— 某些绘制路径没设置 `quadUp`，宽度就落到**法线方向**上 ⇒ 正对基准面看时"没有宽度"。
- 尺寸的界线/半径箭头/角度弧仍有 2D 版本（HUD）。

### 设计
**统一图元：3D 棒（bar）**
- 截面：**宽 W = 0.05 格**（在基准面内，垂直于线段方向） × **厚 T = 0.02 格**（沿基准面法线）
- 每条线段生成 8 个角点 ⇒ **4 个侧面四边形**（上/下/左/右），端面省略（线段两端相接时看不出）
- 宽度方向 `side = normalize(dir × normal)`；厚度方向 `normal`（基准面法线，经渲染 pose 旋转到世界）
- 全部写进 `SKETCH_LINES_QUADS`（QUADS + POSITION_COLOR），与背景网格同一渲染家族

**统一调用点**：`line(...)` → `barLine(...)`。所有草图与尺寸绘制都经过它 ⇒ 不可能再出现 2D 线。

**尺寸几何（全部 3D）**
| 类型 | 画法 |
|---|---|
| 距离 / 水平 / 竖直 / 点到线 / 线线距 | 尺寸线（沿平面内法向偏 0.35 格）+ 两条界线（缝 0.06、超出 0.12）+ 两端箭头（长 0.15、±25°） |
| 半径 / 直径 | 尺寸线**穿过圆心**、只在**圆周端**画箭头；直径两端都画 |
| 角度 | 平面内**折线弧**（半径 0.8 格、16 段）+ 两端**切向箭头**；弧的起止角取两线夹角的较小侧 |

**文字**：仍由 HUD 画（2D 文字渲染是唯一合理做法），但位置 = **投影"尺寸线中点在平面内的位置"**，保证与 3D 线重合。

**验收（自查项）**：正对基准面看 ⇒ 线条有可见宽度；侧看 ⇒ 线条变窄但仍有厚度；`[sketch-quads]` 与 `[dim3d]` 数值正常，无崩溃。

## 2. item 1：旋转拉伸通过点选草图线条选择参考轴

- 现状：`revolveAxis` 只能由"轴按钮"设置（点两次）。
- 目标：在旋转面板激活时，**直接点草图里的一条线** ⇒ 该线成为旋转轴（起点 + 方向）。
- 实现：`SketchClient` 已有"点选图元"能力；在旋转工具激活时把拾取结果交给 `ModelUi.setRevolveAxis(lineVars)`：
  - 轴点 = 线段起点，方向 = (终点 − 起点) 归一化
  - **不接受** construction/reference 以外的限制？—— 接受一切线（辅助线常见作轴）
- 兼容：保留原"点两次定轴"路径作为后备；面板上显示当前轴来源（"已选：草图线"）。

## 3. item 2：通用调色 GUI（新增"调色"设置大项）

- 入口：设置页新增一级项 **调色**，图标用**随机染料**（`Items.DYE` 随机取一个 meta）。
- 第一批 8 项（后续可扩）：
  1. 草图线（idle）  2. 完全定义  3. 选中  4. 悬停  5. 参考几何  6. 尺寸（标注）  7. 网格  8. 预览线框（黄）
- 每项控件：**色块预览 + HSV 取色盘 + 十六进制输入框 + 恢复默认**。
- 存储：`SablestopNowConfig` 新增 `ColorGroup`（8 个 `int` ARGB，默认值 = 现有硬编码常量）。
- 渲染侧：所有硬编码 `float[]` 常量改为 `Colors.sketchLine()` 之类访问器；**保留常量名**以减少改动面。
- 兼容：老配置缺键 ⇒ 用默认值；`verify` 里加"8 项默认值 = 原常量"的断言。

## 4. item 3：文字图元

- 本质：**辅助线矩形**（4 条 construction 线，标 `textBox` 标记）+ 一段文字。
- 创建：工具"文字" ⇒ 拉出矩形 ⇒ 落下后弹 **modify 框**：
  - 输入框（**允许回车换行**，多行文本）
  - 调色（复用 item 2 的调色器）
  - 缩放（0.25–8.0）
  - 旋转（角度，绕**左上角**）
- 双击矩形 ⇒ 再次打开 modify 框。
- 退出草图后：文字**常驻显示**于该位置（世界空间 billboard 文字）。
- 存储：`Sketch` 新增 `TextNote{ u, v, w, h, text, argb, scale, rotationDeg }` 列表（NBT `"texts"`），随草图序列化。
- 渲染：矩形用 `barLine`；文字用 3D billboard（`Font.drawInBatch` + 世界坐标投影），始终面向相机。

## 5. item 4：特征树顺序 = 操作顺序（含依赖与 ↑↓）

### 数据模型
```java
record FeatureRef(FeatureKind kind, UUID id)   // SOLID / PLANE / FILLET / MIRROR / PATTERN
record Feature(UUID id, FeatureKind kind, int index, List<Input> inputs)
enum InputKind { SKETCH, PLANE, EDGE_REF, FACE_REF, FEATURE }
```
- 现有 `Solid`（拉伸/旋转/切割）保持不变，新增 `FeatureOrder`（每个 body 一条有序列表，NBT `"order"`）。
- 新特征类型（圆角/镜像/阵列/基准面）作为新类，不塞进 `Solid`。

### 顺序调整
- 每行右侧 **↑ / ↓** 按钮。
- 移动前做**依赖检查**：
  - 被移动特征引用的输入，其生产者必须仍在它**之前**
  - 移动后不能形成环
  - 违反 ⇒ **拒绝并提示**（`model.order.rejected`），树不动
- 顺序变化 ⇒ 该 body 的特征**按新顺序重建**（重建失败 ⇒ 回滚到调整前并提示）

### 悬停高亮（item 6）
- 树行 hover ⇒ 该特征产生的几何用"特征高亮色"描边（复用 face/edge 高亮的画法）。

### 点击进入 / 删除（item 6.5）
- 点行 ⇒ 左侧面板进入该特征的编辑（拉伸/切割改深度、旋转改角度…）
- 行右侧 **删除** 按钮 ⇒ 删除该特征；**有下游依赖时**：提示"还有 N 个特征依赖它"，允许"级联删除"或取消。

## 6. item 5：模型操作的黄色线框预览

- 统一 `FeaturePreview`：
  - 进入某模型操作（拉伸/切割/基面/圆角/镜像/阵列）即创建预览对象
  - 数值/选择变化 ⇒ 重算预览几何（复用该特征的"求值"函数，输出线框）
  - 渲染：**黄色线框**（颜色来自调色表 item 8），走同一个 `barLine`
- **输入框回车 = 只更新预览**；"确认"按钮 = 提交数据。
- 兼容：现有"点确定直接建"的流程改为"确认才建"；提示语相应调整。

---

## 7. item 7：基准面特征

- 入口：上边栏"新建基准面"。
- 流程：点选一个**参考面**（模型面 / 已有基准面）⇒ 左侧设置**距离**（允许负数）⇒ 黄色预览 ⇒ 确认 ⇒ 在树上新建 `PlaneFeature`（与其它特征同级，遵循顺序/依赖）。
- 新基准面可作为后续草图的基准面（草图的面选择器里出现），也可被其它特征引用（`FACE_REF`/`PLANE`）。
- 存储：`PlaneFeature{ id, sourceRef, distance, index }`，NBT `"planes"`。

---

## 8. item 8：圆角

- 入口：上边栏"圆角"。点选**棱**（复用 `Features` 的棱拾取），左侧设**半径**（预览）。
- 第一版：**等半径、凸棱+凹棱**、多棱**分别倒角后合并**。
- 几何做法：对棱所在的两个面，在棱两侧各内缩 r，生成**四分之一圆柱面**（用弦盒近似，段数按调色/精度设置）+ 裁掉原棱；用 CSG 与实体求交/并。
- 依赖：记录棱的 `EDGE_REF`（所属实体 + 棱的量化端点）⇒ 顺序变化/上游重建后，若棱不存在 ⇒ 该圆角标红并提示。
- 存储：`FilletFeature{ id, List<EdgeRef>, radius, index }`。

---

## 9. item 9：镜像

- 入口：上边栏"镜像"。先点选**镜像面**，再在右边栏点选若干**特征**为被镜像对象；黄色线框预览；确认后生成 `MirrorFeature`。
- 被镜像产物**不单独出现在树上**（它们是该镜像特征的结果）。
- 依赖：镜像面 + 被镜像特征列表；任一项缺失 ⇒ 标红提示。

---

## 10. item 10：阵列

- 入口：上边栏"阵列"。点选 **1–3 条棱**定方向（每方向：次数 N / 间距，可负）；右侧选被阵列特征。
- 结果数 = N × M（两个方向）。
- 产物处理与镜像相同（归在阵列特征下，不单列）。
- 第一版仅**线性双向**；圆周阵列留待后续。

## 11. item 11：连接纹理（Connected Textures）

- 贴图设置面板新增复选框 **"连接纹理"**。
- 勾选且所选纹理带连接信息时：
  - 用**无边框**贴图做填充
  - 识别**有边框**贴图中的边框，按 Project 的特征（面/棱/角）套用边框
- 连接元数据按 **Chisel/CTM** 社区事实标准（`ctm` 元数据），这样纹理包直接可用。
- 第一版范围：**平面面**的边框连接（棱/角后续补）。

## 12. item 12：草图 Ctrl+Z

- 在草图编辑中捕获 `Ctrl+Z`（同时支持 `Ctrl+Y`/`Shift+Ctrl+Z` 重做）。
- 实现：`SketchSession` 维护**快照栈**（变量数组 + 图元 + 约束 + 标记位），每次修改前 push（上限 64），`undo/redo` 恢复快照后重建索引。
- 与求解器：undo 后**不自动重解**（保持快照即状态），但 `SketchDof` 重算。

## 15. 风险与对策

| 风险 | 对策 |
|---|---|
| 3D 棒顶点数暴涨（每段 16 顶点） | 只对**可见**草图绘制；顶点上限保护；必要时按距离剔除 |
| 特征顺序重建失败 | 重建前快照，失败回滚 + 提示 |
| 圆角 CSG 退化 | 半径上限（< 相邻面最短边/2）；失败则该特征标红，不影响其它 |
| 调色配置破坏旧档 | 缺键用默认；`verify` 断言默认值 = 原常量 |
| 文字 3D 渲染性能 | 每个文字元素只画一次 quad；文本内容变化才重建缓冲 |
