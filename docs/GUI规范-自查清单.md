# GUI 规范 · 自查清单（每个 GUI 里程碑必过）

> 由来：曾为调试把某个 GUI 面板**未经说明设为始终置顶**，调试完忘了撤销，额外花了好几轮才改回来。
> 从那以后：任何调试用置顶/高亮都必须当场移除，或做成默认关闭 + 启动打印状态的开关。

## 层与优先级
| 层 | 内容 | 备注 |
|---|---|---|
| 0 | 上边栏 | 永远在最上 |
| 1 | 左/右边栏 | 互不遮挡；不与上边栏重叠 |
| 2 | 画布浮层（尺寸标签、picker 提示） | 不拦截鼠标，除非明确是控件 |
| 3 | modify 框 / 小编辑框 | 打字时**绝不重建**（否则丢焦点） |
| 4 | 模态对话框（调色、确认） | 独占输入，必须有 ESC/取消 |

## 逐项自查
1. 新增面板**默认不置顶**？调试开关已删除？
2. 同一层内控件不互相覆盖；左右栏高度让出上边栏。
3. 所有弹窗有**关闭路径**（ESC / 取消 / 点外部）。
4. 回车语义：模型操作 = **只更新预览**；modify 框 = 提交该尺寸。
5. 颜色不硬编码，走调色表（item 2）。
6. 面板重建用**内容指纹去重**，不得每帧重建。
7. 新按钮有 tooltip；中英语言键数量一致（`verify` 会断言）。
8. 关闭面板后：预览对象释放、选择清空、临时状态复位。
9. 输入框聚焦时：鼠标点击其它控件不得抢焦点。
10. 新增 GUI 若引用"当前选中特征"，必须处理"选中项被删除"的空指针。
