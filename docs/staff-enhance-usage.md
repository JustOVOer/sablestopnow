# 物理手杖增强（Staff Enhance）—— 使用说明

> 适用版本：**Aeronautics: Tweaks & Toolkit 1.1.0**（NeoForge 1.21.1 / Sable 2.0.4 / Simulated-Aeronautics 1.3.1）。
> 总开关：游戏内 `Ctrl+O` 打开设置界面 →「物理手杖」→ `enable_staff_enhance`（也可直接改 `config/sablestopnow-common.toml` → `[staff_enhance]`）。
> 除特别说明外，手杖相关功能都要求**手持物理手杖（PhysicsStaffItem，主手或副手）且未打开 GUI**。

## 1. 按键（全部是 Minecraft KeyMapping，可在「选项 → 按键控制 → Aeronautics: Tweaks & Toolkit」里改）

| 键 | 默认 | 作用 |
|---|---|---|
| 多选模式 | 左 Ctrl | 进入/退出多选模式；进入时会把手里的选中队列重新登记为「我的」 |
| 区域选择 | Z | 进入/取消区域选择（见 §3） |
| 整组无碰撞 | V | 对**整个选中队列**切换无碰撞标记 |
| 整组归中 / 视角锁定 | C | 整组控制中=把质心缓拉向视线中央；其余情况（非多选）=长按锁定视角 |
| 所有权 | O | 对选中队列设置/取消所有权 |
| 快照 | K | 创建/取消快照（整个选中队列一份） |
| 回退快照 | R | 把快照整体回退到创建时的状态 |
| 缩放 | X | 按住 X + 滚轮缩放选中队列（见 §7） |
| 穿透修饰键 | 左 Alt | 配合滚轮调「穿透层数」（任何时候可用） |
| 打开设置界面 | Ctrl+O | 打开本模组设置界面（不需要持杖） |

> 鼠标：右键/Shift+右键/左键/中键/滚轮由客户端 Mixin 拦截（多选与区域选择期间会**吞掉**原手杖交互）。

## 2. 多选与选中队列

- **进入/退出**：Ctrl。退出后队列**保留**（可继续整组拖拽），但服务端占用会**立即释放**，别人可接手。
- **加入/移出**：多选模式右键加入、Shift+右键移出；左/中键被吞掉。
- **独占**：同一物理结构同一时刻只能被一个玩家选中。已被他人选中、或已被他人**拥有**的结构，你右键/区域选择都会被拒绝并在聊天栏提示是谁。
- **颜色**：描边颜色由服务端按玩家分配（12 色调色板），不同玩家不同色；别人的选择会同步给你，**只在同维度 + 64 格内**渲染（线条略细）。
- **整组拖拽**：退出多选后（队列非空）对准队列成员右键进入；滚轮调距离、TAB+鼠标旋转、长按 C 归中、右键结束；左键=整队列锁定切换、V=整队列无碰撞切换。

## 3. 区域选择（Z）

1. 按 Z 进入区域选择（**不要求先开多选**）；HUD 显示「区域选择·选第一点」与选择点距离；
2. **滚轮**调选择点到玩家的距离（1–128 格，按住疾跑键 ×4），**视线**定方向；此时预览框是**一个方块大小**，指示第一个选择点；
3. **右键**确定第一个角点 → 进入选第二点，此时**实时描边「将会被选中」的物理结构**（黄绿色），HUD 显示距离/指示点/将选中数量，预览框是第一、第二点框出的长方体；
4. 第二个点**右键**确定 → 把长方体相交的物理结构全部加入队列；再按 **Z** 取消；
5. 区域选择的滚轮会被吞掉，**不会切快捷栏**。

## 4. 所有权（O）

- 选中若干结构后按 **O**：把它们设为你所有；队列**全部已是你的**时再按 O 就取消。
- 已属于他人的不能被别人设置，也不能被别人选中（多选/区域选择都会被拒）。
- 所有权**写入存档**（SavedData），跨重启保留。
- 准星落在某结构上时 HUD 显示「所有者：xxx」。
- OP 命令：`/sablesn owner list`、`/sablesn owner clear <玩家名>`、`/sablesn owner clear all`。

## 5. 快照 / 回退（K / R）

- 选中队列后按 **K**：存一份快照；已存快照的结构上方会显示**浅蓝色「相机」图标**；再按 K 取消。
- 按 **R**：把快照整体回退。内部做法是「按 `REMOVED` 移除当前结构 → 用同一 UUID `fullyLoad` 快照数据 → 按快照原值写回速度」，因此**方块 / 位置 / 朝向 / 速度 / 名称**都回到创建快照那一刻。
- 快照**按玩家独立**，且是**运行期内存**（服务器重启/退世界即失效）。
- 回退会有一瞬间的重生；挂在结构上的其它模组关联（例如 Create 的 contraption 挂接）不保证恢复。

## 6. 视角锁定（C）


- 手持手杖、**不在多选、也不在整组控制**时，长按 **C**：每 tick 重新选取「与视线夹角最小」的已加载物理结构，把视线锁定指向它；松开即解锁。
- 锁定期间鼠标转视角被冻结（转动由渲染插值平滑）；HUD 显示「视角锁定：xxx」。
- 整组控制中 C 仍然是「归中」。

## 7. 缩放（X + 滚轮）

- 选中队列后**按住 X 滚轮**：按 `scale_sensitivity`（默认 0.08）缩放整组，范围 `scale_min`…`scale_max`（0.2–8.0）。
- **保持形状**：以整组**公共质心**为基准缩放，各成员相对质心的位置与朝向一起缩，因此不会散架或错位。
- HUD 显示当前缩放倍率；准星指向的物理体缩放 ≠ 1 时，HUD 额外显示「该结构缩放：×N」。
- **首次按 X 会先把混合倍率归一化到 1.0**（`mixed scales → 1.0`），再开始缩放，避免出现「越滚越乱」。
- 缩放倍率由模组自己同步（Sable 的 `SableBufferUtils` 只序列化 position/orientation/rotationPoint，**不含 scale**），写入存档并跨重启保留。
- 客户端渲染由两个 Mixin 补上 Sable 漏掉的缩放矩阵：`VanillaChunkedSubLevelRenderScaleMixin`（常规区块渲染路径）、`FancySubLevelRenderScaleMixin`（高级渲染调度器）。

## 9. 幽灵化 / 无碰撞（V 与两个 config）

- **V**：对**整个选中队列**切换无碰撞标记（存档保存）。
- 新增两个配置（默认 `true`）：
  - `dragged_no_player_collision`：**正在被拖拽的物理体**不再与**拖拽它的玩家**碰撞；
  - `scaled_no_player_collision`：**被缩放过（scale ≠ 1）的物理体**对所有玩家不碰撞。
- 实现要点：玩家与物理结构的碰撞实际在**客户端**结算（`ServerPlayer` 分支会被 Sable 提前返回一个「假地面」），所以幽灵状态必须同步给客户端；`SubLevelEntityCollisionGhostMixin`（common）挂在 `SubLevelEntityCollision.collide` 里**唯一**一次 `getAllIntersecting` 调用上，按 `PhysicsGhosts.ignores(sub, player)` 过滤。
- 已知残留：幽灵化只关掉**碰撞**，`getTrackingSubLevel` 的搭车逻辑仍在（站上去/贴住还是会被带走）。

## 10. 显示 / 描边（工程师护目镜）

- **选中/悬停轮廓**：细长长方体盒（Create 蓝图/强力胶同款视觉），粗细 `staff_outline_thickness`；准星指向队列成员时**整组加粗** `staff_outline_bold_scale` 倍。
- **物理结构描边**（`[force_limiter]` 段）：`render_sub_level_outlines` 开启后给所有物理体描边；
  - `outline_only_contour` = 只描暴露棱线（盒式，粗细 `outline_thickness`，**已修复“多描一圈向内接缝”**）；
  - 未开 `outline_only_contour` 时是整块线框（GL 线），两种模式视觉不同；
  - `outline_always_visible` 穿墙可见；`outline_only_focused` 只描准星所指；`render_axis` + `axis_angle_degrees` 画动态缩放的三色坐标轴。
- **图标**：选中=圆环十字（我的颜色）、无碰撞=橙色方块环、快照=浅蓝相机方块、区域选择候选=黄绿轮廓。

## 11. HUD（左上角）

有事情在做时才显示：多选模式 / 区域选择·第几点 / 整组控制 / 整组待命 / 视角锁定 / 穿透层数 / 已选中数量 / 准星瞄准的物理结构名 / 所有者 / 区域选择距离与将选中数量 / 当前缩放倍率 / 准星所指结构的缩放倍率。

## 12. 设置界面（Ctrl+O 或模组列表「配置」）
- 大类选择页：左侧蓝色色块从上到下出现、标题从左到右、三个大类依次滑入；离开反向。
- 大类详情页：图标移动并放大、右侧蓝色色块从左往右出现、设置项从右往左沿折线轨迹依次出现；ESC 返回。
- 三个大类：**物理组装器**（力过滤/自动暂停/超速锁定等 Sable 本体改动）、**物理手杖**（staff_enhance + 打开按键设置）、**工程师护目镜**（显示/描边/坐标轴）。
- 所有文字都是「中文 | English」；改动**立即写回 `config/sablestopnow-common.toml`**。

## 13. 附加功能

- `/sablesn tick <steps>`：物理已暂停时步进 N 个物理 tick 后自动恢复暂停（权限 2）。
- `/sablesn forces [filtered] [page]`：力记录列表（可点击传送）。
- 超速自动锁定（`speed_limit_enabled`）：超过 `speed_limit_threshold` 格/秒自动锁定并广播；被拖拽的物理体豁免。

## 14. 已知限制

- `ghost_real=false` 时 V 只做视觉 + 存档占位（Sable 无运行期按体 ghost API）；`true` 时也只关掉**选中体之间**的碰撞。
- **缩放是「视觉 + 玩家碰撞」层面的**：Rapier 的碰撞体与质量**不会**跟着缩放，缩放体之间的物理仍按原尺寸结算；Sable 的序列化会丢掉 scale，所以由本模组自己持久化。
- 幽灵化只关碰撞，Sable 的搭车（tracking）逻辑仍在：站上去仍可能被带走。
- 整组控制是逐成员马达驱动，大结构/高速下可能有轻微弹动（刚度/阻尼是实测经验值）。
- 快照不落盘；回退是「移除+重建」。
- 超速锁定的豁免依赖对航空学内部拖拽会话的反射（版本锁定于内置 1.3.1）。
