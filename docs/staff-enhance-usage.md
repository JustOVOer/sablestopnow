# 物理手杖增强（Staff Enhance）—— 使用说明

> SableStopNow 的物理手杖增强功能（NeoForge 1.21.1 / Sable 2.0.4 / Simulated-Aeronautics 1.3.1）。
> 总开关：`config/sablestopnow-common.toml` → `[staff_enhance]` → `enable_staff_enhance = true`。

## 按键（默认；均为 GLFW 键码，可在 config 改）

| 键 | 状态 | 作用 |
|---|---|---|
| Ctrl（341） | 持杖任意时 | 进入/退出多选模式（进入后原手杖拖拽/锁定被接管禁用） |
| 右键 | 多选模式 | 把指向物理体**加入**选中队列（已加入则提示） |
| Shift+右键 | 多选模式 | 把指向物理体**移出**选中队列 |
| Alt+滚轮 | 多选模式 | 调视线穿透层数（0–16），决定点选第 N+1 层物理体 |
| Z（90） | 多选模式 | 范围选择：两次都在**玩家所在块**标点，玩家移动后第二次确认 → AABB 选区内的物理体全部入队（实时预览第二个角点=当前玩家块） |
| 左键 | 多选模式 | 禁用（防误触原手杖） |
| Ctrl 退出 | 待命态 | 队列保留（armed） |
| 右键组内成员 | 待命态 | 先**解除全部选中体锁定**，再进入**整组控制** |
| Shift+右键 | 待命态 | **清空选中队列** |
| 左键 | 待命态 / 整组控制中 | 智能锁定切换：全部已锁定→全部解锁；否则（含部分锁定）→ 先全部锁定 |
| 滚轮 | 整组控制中 | 沿“眼睛→质心”连线缩放整组距离 |
| 长按 C（67） | 整组控制中 | 让质心**缓慢**滑到视线中央（速度可配） |
| TAB+鼠标移动 | 整组控制中 | 绕质心旋转整组（视角冻结；与航空学手感一致） |
| 右键 | 整组控制中 | 结束整组控制（队列保留，仍待命） |
| V（86） | 非多选（无队列） | 切换指向物理体“无碰撞”标记（橙色图标；Sable 暂不支持真实穿模，为视觉+存档占位） |
| 放手杖 | 任意 | 清空所有增强状态 |

## 行为要点

- **悬停预览**：多选模式下准星指向的“将选中体”只显示亮白轮廓（无图标）；只有入队的才显示青色描边轮廓+圆环图标，颜色统一。
- **描边风格**：选中/悬停用“只描暴露棱线（轮廓）”模式，不画平坦表面内部接缝。
- **整组控制**：进入时按**视线坐标系**记录“质心−眼睛”的前/右/上分量 → 起步无瞬移；转视线可拖动整组环绕；移动/走路整体平移；滚轮沿眼心线调距；长按 C 缓拉视线中央。
- **锁定/解锁**：复用航空学 FixedConstraint 锁定；锁定状态 S2C 同步，提示按服务端真实状态给出。

## config（`[staff_enhance]` 段）

| key | 默认 | 说明 |
|---|---|---|
| `enable_staff_enhance` | false | 总开关 |
| `key_multi_select` | 341 | Ctrl（GLFW 键码） |
| `key_box_select` | 90 | Z |
| `key_collision_toggle` | 86 | V |
| `key_center_pull` | 67 | C（整组归中） |
| `rotate_sensitivity` | 0.35 | TAB 旋转灵敏度 |
| `scroll_sensitivity` | 0.6 | 滚轮（穿透层/整组距离） |
| `center_pull_speed` | 0.06 | 长按 C 的归中速度（每 tick 比例） |

> 改配置后重启游戏生效。TAB（旋转）复用航空学“Physics Staff Rotate Mode”键位，可在其按键设置里改。

## 已知限制

- “无碰撞”为占位（Sable 无运行期按体 ghost API）；仅视觉图标+服务端存档同步。
- 整组控制基于逐成员马达驱动；高速/巨大结构可能有轻微弹动，可调 `[staff_enhance]` 的旋转/滚轮灵敏度，或改 `server/StaffEnhanceServer` 中的刚度/阻尼常量（线性 2650/125、角向 10000/850）。
- 键位为 config 键码，尚未做成 Minecraft Controls 按键绑定（后续可迁 KeyMapping）。
