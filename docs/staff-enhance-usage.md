# 物理手杖增强（Staff Enhance）—— 使用说明

> 适用版本：**SableStopNow 1.0.4**（NeoForge 1.21.1 / Sable 2.0.4 / Simulated-Aeronautics 1.3.1）。
> 总开关：`config/sablestopnow-common.toml` → `[staff_enhance]` → `enable_staff_enhance = true`（默认 false）。
> 全部功能**仅在手持物理手杖（PhysicsStaffItem，主手或副手）且未打开 GUI 时**响应。

## 1. 按键（默认；均为 GLFW 键码，可在 config 改）

### 多选模式（Ctrl 进入后）

| 键 | 作用 |
|---|---|
| Ctrl（341） | 进入/退出多选模式。进入后原手杖右键拖拽/左键锁定被**完全接管禁用** |
| 右键 | 把准星指向的物理体**加入**选中队列（已在队列则提示“已在队列”） |
| Shift+右键 | 把指向物理体**移出**选中队列 |
| Alt+滚轮 | 调视线穿透层数（0–16），决定“穿透 N 个物理体后的第 N+1 个”被点选 |
| Z（90） | 范围选择：第一次按 Z 标记**玩家所在方块**为角点 A；移动后第二次按 Z 以**玩家所在方块**为角点 B → 实时预览第二个角点，确认后把 AABB 内所有物理体入队（上限 100 万格） |
| 左键 / 中键 | 吞掉（防误触原手杖交互） |

### 整组待命态（Ctrl 退出多选后，队列非空）

| 键 | 作用 |
|---|---|
| 右键组内成员 | **先解除全部选中体的锁定**，再直接进入**整组控制**（起步无瞬移） |
| Shift+右键 | **清空选中队列**（同时弃用了原有的“右键清除”方式） |
| 左键 | 智能锁定切换：全部已锁定 → 全部解锁；否则（含部分锁定）→ 先全部锁定 |
| V（86） | 对**整个选中队列**切换“无碰撞”标记（语义与左键锁定一致：全部已标记→取消，否则→先全标记）；队列为空时提示“请先选中物理体” |

### 整组控制中（已进入整组拖拽）

| 键 | 作用 |
|---|---|
| 右键 | **结束整组控制**（队列保留，回到待命态） |
| 左键 | 智能锁定切换（同上） |
| 滚轮 | 沿“眼睛 → 整组质心”连线缩放整组距离 |
| 长按 C（67） | 让质心**缓慢**滑到视线中央（速度可配，默认 0.06/tick） |
| TAB + 鼠标移动 | 绕质心旋转整组（视角冻结；手感对齐航空学，复用其旋转模式键） |
| V（86） | 队列无碰撞切换（同待命态） |
| 移动/走路 | 整组随之整体平移（质心保持相对视线方向的前/右/上分量） |

### 其他

| 键/操作 | 作用 |
|---|---|
| 放手杖（切到别的物品） | 清空所有增强状态（队列、模式、组会话） |

## 2. 行为要点

- **悬停预览**：多选模式下准星指向的“将选中体”只显示**亮白轮廓**（无图标）；只有真正入队的才显示**青色描边轮廓 + 圆环图标**，颜色统一。
- **描边风格**：选中/悬停用“只描暴露棱线（轮廓）”模式，不画平坦表面内部接缝。
- **点选拾取（关键实现）**：Sable 的物理体是**位姿渲染**的（`logicalPose`/`renderPose`），世界坐标 `Sable.HELPER.getContaining` 只认**基准网格坐标**，因此点选必须走 Sable 自己的**位姿感知射线**：客户端给 `LevelPoseProviderExtension.sable$pushPoseSupplier(x -> renderPose())` 后调 `level.clip`，命中的坐标是**基准坐标**，再 `getContainingClient` 反查物理体。
- **整组控制**：进入时按**视线坐标系**记录“质心 − 眼睛”的前/右/上分量（`offsetF/offsetR/offsetU`），所以起步不瞬移；转头可拖动整组环绕；走路整体平移；滚轮沿眼心线调距；长按 C 缓拉视线中央。服务端对**每个成员**各挂一个 FreeConstraint 马达，每个物理子步驱动到“目标位姿”，因此**保持相对位姿**（不是焊接吸在一起）。
- **锁定/解锁**：复用航空学 FixedConstraint 锁定；锁定状态经 S2C（`SyncLocks`）同步，提示按服务端真实状态给出。
- **无碰撞标记**：状态由服务端 `StaffCollisionData`(SavedData) 持久化 + `SyncNoCollision` S2C 同步，橙色方块图标。
  - `ghost_real = false`（默认）：纯视觉+存档占位，**不真实穿模**。
  - `ghost_real = true`：实验性真实生效——对**邻近**（160 格内）的选中体两两创建 `GenericConstraintConfiguration`（锁定轴集合为空）+ `setContactsEnabled(false)` 的**瞬态“无碰撞关节”**，使选中体**之间**不再碰撞；**地形与玩家仍正常碰撞**。关节随物理子步刷新，退出/失效自动清理。
- **整组碰撞（V）与左键一致**：作用于整个队列，不是准星单体。

## 3. 顶部 HUD

启用增强并持杖时，屏幕**左上角**持续显示（`RenderGuiEvent.Post`）：

| 行 | 内容 |
|---|---|
| 1 | 状态：`多选模式 ON` / `整组待命` / 整组控制 |
| 2 | `穿透层数：N` |
| 3 | `已选中：N` |
| 4–5 | 框选时显示 `框选角点A：x, y, z` / `框选角点B：x, y, z` |

## 4. 附加功能（v1.0.4）

### 4.1 物理步进命令 `/sablesn tick <steps>`

需要在物理**已暂停**时使用（权限等级 2）：

- 每条 `tick` 让被暂停的世界物理**步进 N 个物理 tick，然后自动恢复暂停**。
- 未暂停时提示“物理未暂停，无法步进”。
- 实现：`StaffEnhanceServer.startStepping(level, steps)` 先取消暂停，每个 `ServerTickEvent.Post` 递减计数，归零后重新暂停。

### 4.2 超速自动锁定（force_limiter 段）

- `speed_limit_enabled = true` 后启用：物理体线速度超过 `speed_limit_threshold`（默认 15.0 格/秒）时**自动锁定**并在聊天栏广播。
- 广播文案带**可点击的 `[点击传送]`**（`RUN_COMMAND` 填充 `/tp @p x y z` 到该物理体位置），与 `/sablesn forces` 的传送一致。
- **不会锁定正在被人为拖拽的物理体**：
  - 本模组整组控制中的成员；
  - 航空学普通单人拖拽中的物理体（反射读取 `PhysicsStaffServerHandler` 中的拖拽会话）。
- 每物理体 60 tick 冷却（`SPEED_LOCK_RETRY`）且仅在**确认确实变为已锁定**后才播报，避免刷屏。

## 5. config（`[staff_enhance]` 段）

| key | 默认 | 说明 |
|---|---|---|
| `enable_staff_enhance` | false | 总开关（关闭时全部不生效：不拦截输入、不渲染、不改手杖行为） |
| `key_multi_select` | 341 | Ctrl（GLFW 键码） |
| `key_box_select` | 90 | Z |
| `key_collision_toggle` | 86 | V |
| `key_center_pull` | 67 | C（整组归中） |
| `rotate_sensitivity` | 0.35 | TAB 旋转灵敏度 |
| `scroll_sensitivity` | 0.6 | 滚轮（穿透层/整组距离） |
| `center_pull_speed` | 0.06 | 长按 C 的归中速度（每 tick 比例） |
| `ghost_real` | false | V 是否**真实**关闭选中体之间的碰撞（实验性，见 §2） |

`[force_limiter]` 段相关：

| key | 默认 | 说明 |
|---|---|---|
| `speed_limit_enabled` | false | 超速自动锁定总开关 |
| `speed_limit_threshold` | 15.0 | 速度阈值（格/秒） |

> 改配置后重启游戏生效。TAB（旋转）复用航空学 “Physics Staff Rotate Mode” 键位，可在其按键设置里改。

## 6. 已知限制

- `ghost_real = false` 时“无碰撞”仅为视觉+存档（Sable 无运行期按体 ghost API）；开启后也只关掉**选中体之间**的碰撞，不影响地形/玩家。
- 整组控制基于**逐成员马达**驱动；高速/巨大结构可能有轻微弹动，可调灵敏度，或改 `server/StaffEnhanceServer` 中常量（线性 2650/125、角向 10000/850）、`GHOST_SEARCH_SQ`（160 格搜索半径）。
- 反射依赖航空学内部类结构（拖拽会话），**版本锁定于内置 1.3.1**；升级航空学可能失效（失效时表现为普通拖拽体也会被超速锁定，功能本身不崩）。
- 键位是 config 键码，尚未做成 Minecraft Controls 按键绑定（未迁 KeyMapping）。
- 整组控制的大结构手感（刚度/阻尼）仍需实测调参。
